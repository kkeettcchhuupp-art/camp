# camp

キャンプ道具を整理するためのブラウザアプリ（Camp Gear Organizer）。
`index.html` をブラウザで開くだけで使えます（インストール不要）。

## 機能

- **ギア一覧**：写真・名称・カテゴリ・メーカー・数量・重量・寸法（使用時 / 収納時の 幅×奥行×高さ）・収納場所・状態（良好 / 要修理 / 要補充）・メモを登録。キーワード・カテゴリ・収納場所・状態で絞り込み。写真はタップで拡大。
- **持ち物リスト**：キャンプごとに持っていくギアを選び、積み込みチェック。進捗・合計重量・収納時寸法から求めた合計容積・要修理/要補充の警告を表示。前回のキャンプから複製、印刷にも対応。
- **キャンプ履歴**：キャンプごとに日付・場所・メモ、持って行ったギア（写真付き）、そのキャンプの写真（1キャンプ1枚）を一覧表示。写真の追加・変更・削除、キーワード検索、回数集計、よく持って行くギアのランキング。ギア一覧には各ギアの持参回数と最終持参日を表示。
- **データ**：ブラウザに自動保存（写真は縮小して IndexedDB に保存）。JSON の書き出し・読み込み（ギア写真・キャンプ写真も含む）、CSV 書き出し、サンプルデータ追加。

レイアウト検討は [camp-layout-planner](https://github.com/kkeettcchhuupp-art/camp-layout-planner) を使用してください。
