# ソトログ — キャンプ履歴・ギア管理

キャンプの思い出と道具を、まるごと記録するブラウザアプリです。
インストール不要。スマホでは「ホーム画面に追加」するとアプリのように使えます。

**公開 URL：https://kkeettcchhuupp-art.github.io/camp/**

## タブ構成

| タブ | できること |
|---|---|
| ギア登録 | 新しいギアを登録（写真・カテゴリ・メーカー・数量・重量・使用時 / 収納時の寸法・収納場所・状態・メモ） |
| ギア一覧 | 登録したギアをカテゴリ別のカードで表示。検索・絞り込み。カードをタップして内容を修正・削除 |
| キャンプ登録 | キャンプ名・日付・場所・メモ・写真（1枚）を登録。必要に応じて持って行ったギアも選択。登録済みキャンプの編集 |
| キャンプ履歴 | これまでのキャンプを一覧表示。持ち物チェック（積み込み確認・印刷）、同じ持ち物で新規登録、よく持って行くギアのランキング |
| データ | バックアップの保存・復元、CSV 書き出し、ホーム画面への追加方法、友だちへの共有、使い方の案内 |

## スマホで使う

- **ホーム画面に追加**するとアプリのように全画面で使えます。
  - iPhone（Safari）：共有ボタン →「ホーム画面に追加」
  - Android（Chrome）：メニュー →「ホーム画面に追加」/「アプリをインストール」
- 一度開けば、電波のないキャンプ場でもオフラインで使えます。
- データは端末ごとのブラウザに保存されます（ほかの人には見えません）。
- 最後のバックアップから 14 日たつと、画面上部でバックアップを促します。スマホでは共有メニューから「ファイルに保存」や iCloud Drive / Google ドライブに保存できます。
- iPhone では、ホーム画面に追加せず Safari だけで使っていると、しばらく開かない間に保存データが消えることがあります。ホーム画面に追加して使うのがおすすめです。

## 開発メモ

- `index.html` 1 ファイルのアプリです。イラストはすべてインライン SVG。
- 保存先：ギア・キャンプは localStorage（`campGearOrganizerV1`）、写真は IndexedDB（`campGearOrganizerPhotos`）。
- GitHub Pages：Settings → Pages で `main` / `(root)` を公開。
- `index.html` などを変更したときは、`sw.js` の `CACHE` の番号（`camp-gear-v2` → `v3` …）を上げてください。オフライン用のキャッシュが更新されます。
- レイアウト検討は [camp-layout-planner](https://github.com/kkeettcchhuupp-art/camp-layout-planner) を使用してください。
