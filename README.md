# camp

キャンプ道具を整理するためのブラウザアプリ（Camp Gear Organizer）。
`index.html` をブラウザで開くだけで使えます（インストール不要）。

## 機能

- **ギア一覧**：名称・カテゴリ・メーカー・数量・重量・収納場所・状態（良好 / 要修理 / 要補充）・メモを登録。キーワード・カテゴリ・収納場所・状態で絞り込み。
- **持ち物リスト**：キャンプごとに持っていくギアを選び、積み込みチェック。進捗・合計重量・要修理/要補充の警告を表示。前回のキャンプから複製、印刷にも対応。
- **データ**：ブラウザ（localStorage）に自動保存。JSON の書き出し・読み込み、CSV 書き出し、サンプルデータ追加。

レイアウト検討は [camp-layout-planner](https://github.com/kkeettcchhuupp-art/camp-layout-planner) を使用してください。
